# Movie Library

Автор: Варвара Юрьева

## Описание
Простое GUI-приложение на Python с использованием tkinter для хранения информации о фильмах:
- добавление фильмов
- фильтрация по жанру и году
- сохранение и загрузка данных в JSON файл
- контроль корректности ввода

## Использование
1. Запустите `main.py`.
2. Введите название, жанр, год и рейтинг фильма.
3. Нажмите "Добавить фильм".
4. Для фильтрации выберите жанр или год из списков. Можно выбрать "Все" для снятия фильтра.
5. Данные сохраняются автоматически при добавлении.

## Требования
- Python 3.x
- Библиотека tkinter (обычно идет в стандартной поставке)

## Возможные тесты
- Добавить несколько фильмов с разными жанрами и годами.
- Провести фильтр по жанру или году.
- Попробовать ввод некорректных данных (например, отрицательный рейтинг или нечисловой год) — увидите сообщение об ошибке.
